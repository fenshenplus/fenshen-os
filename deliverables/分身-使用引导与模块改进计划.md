# 分身 · 使用引导体系 + 分模块改进计划

> 状态：方案稿（待确认后实施）｜日期：2026-08-18
> 决策已确认：① 官网/文档站 = 新建独立 **fenshen-docs 静态站**；② 本稿仅出方案，不写代码。

---

## 一、总目标

让新用户（与回归用户）能在 **15 分钟内理解"分身是什么、怎么用"**，并让每个模块都"看得懂、用得动、信得过"。

引导分两层、内容同源：

| 层 | 载体 | 定位 | 关键指标 |
|---|---|---|---|
| 产品内引导（in-app） | fenshen-v1 前端 | 降低上手门槛，场景化、可跳过、零侵入 | 首项目成立率、空状态转化率 |
| 官网文档站（fenshen-docs） | 独立静态站 | 系统化教程/概念/FAQ/API/更新日志，承担"深度学习与检索" | 文档覆盖率、搜索命中率 |

**内容同源原则**：官网 MD 与产品内引导文案由同一份"内容清单"派生，避免漂移。约定：产品内短文 = 官网对应页的"摘要段"。

---

## 二、产品内引导方案（复用现有机制，不重造）

### 现状可复用
- 成立项目向导（3 步：目标 / 角色 / 模板模块）— 已上线
- v5.1 首次使用引导（元神软门槛 3 步，可跳过）— 已上线
- P1-1 分步导览（`window._tour` 高亮机制）— 已上线
- 「关于分身」页 — 现仅产品信息，非教程

### 规划"四件套"
1. **首用向导增强**（基于 v5.1 + 项目向导）
   - 首次启动：3 步软门槛（培养元神可选）+ 一键"成立第一个项目"直通项目向导。
   - 落库 `meta_settings` 新键 `onboarding_done=1`，仅首次展示，可跳过。
2. **空状态提示 Empty-state**（新增，低成本高回报）
   - 每个模块（对话 / 看板 / 角色库 / 技能库 / 经验库 / 长期记忆 / 进化中心…）首次为空时，显示「这是什么 + 第一句该做什么 + 一个按钮」。
   - 例：经验库空 → *"经验库是元神踩坑/成功经验的自进化沉淀，随你使用自动累积；当前 0 条，开启进化开关后开始积累。"*
3. **分步导览 Guided Tour**（基于 P1-1 `window._tour` 扩展）
   - 每个核心模块一套 step（高亮锚点 + 气泡文案），首次进入或点「?」触发。
   - 覆盖：对话群聊 / 元神驾驶舱 / 项目看板 / 角色库 / 蒸馏(my分身) / 进化中心。
4. **帮助中心 Help Hub**（在「关于分身」扩展为「帮助中心」）
   - 内嵌搜索 + 分模块短文 + 跳转官网对应页。复用产品 UI 令牌，零额外部署。

**实现纪律**：所有引导文案来自单一常量 `IN_APP_GUIDE`（JS/JSON），便于与官网同步、便于 i18n。所有新增引导默认关或"仅首次"，保持零侵入（与 code_*/evolution_* 开关一致）。

## 三、官网文档站方案（fenshen-docs 静态站）

### 选型建议
Markdown 源 + 静态生成器。**推荐 VitePress**（轻、快、内置搜索好）；备选 Docusaurus。与产品解耦，部署到分身品牌域或子路径（如 `fenshen.xxx/docs`）。

### 信息架构（IA）
```
fenshen-docs/
├─ 首页（是什么 / 为什么 / 30 秒上手）
├─ 快速开始（5 分钟跑通第一个项目）
├─ 概念（群聊=项目 / 元神 / 角色 / 看板 / 蒸馏 / 自进化引擎 / 续航）
├─ 模块指南（每模块一篇：是什么 + 怎么用 + 技巧 + FAQ）
│   ├─ 对话·群聊 AI 团队总管
│   ├─ 元神·我的分身（蒸馏）
│   ├─ 元神驾驶舱
│   ├─ 角色库
│   ├─ 公共资源库
│   ├─ 模型设置
│   ├─ 终端 / 浏览器
│   ├─ 项目看板
│   ├─ 清理中心
│   ├─ 长期记忆
│   ├─ 技能库
│   ├─ 经验库 / 进化中心
│   ├─ 元神续航
│   └─ 应用市场
├─ 进阶（自进化引擎原理 / 护栏 / lineage；蒸馏授权伦理；账号归属权）
├─ 教程（场景化：蒸馏我自己 / 让元神自动驾驶一个项目 / 团队协作）
├─ API 参考（/api/meta/*、/api/projects 等）
├─ 常见问题 FAQ
├─ 更新日志（接 CHANGELOG.md）
└─ 安全与隐私（元神宪法 / 蒸馏授权 / 数据归属）
```

### 内容同源
官网 MD 与产品内 `IN_APP_GUIDE` 由同一份"内容清单"派生。产品内短文 = 官网对应页"摘要段"，避免双份维护漂移。

### 部署
静态产物 → 对象存储/静态托管（复用现有阿里云/CloudStudio），域名走分身品牌域或子路径。

## 四、分模块改进清单（按优先级）

> 现状基于 fenshen-v1（0.64.8）代码与记忆；标注是否需教程配套。

### P0 — 上手 / 信任关键
| 模块 | 现状 | 待改进 | 教程配套 |
|---|---|---|---|
| **长期记忆 memory** | E6 无损归档后端就位，无浏览器 UI / 导出 / 隐私开关 | 记忆面板 + 导出/导入 + 隐私控制 | "记忆怎么用、归属谁" |

- **移动端通讯器（Flutter）**：功能 parity / 推送；教程"手机上怎么用分身"。
- **安全合规**：元神宪法、蒸馏授权、隐私声明的产品内透出。
