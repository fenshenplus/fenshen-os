## 三、问题清单（按严重度）

### 🟡 Medium（应修）

**M1 — `_load_dotenv` 不识别 `export KEY=val`（作者已列，我复核确认且后果更明确）**
`main.py:55` `_line.split("=", 1)`。若某行是 `export FOO=bar`，`_k` 得 `"export FOO"`（含空格），随后 `os.environ["export FOO"]="bar"` —— **写入一个错误命名的变量**，真正的 `FOO` 仍为空。不是"静默忽略"，而是"写错 key"。建议正则 `^\s*(?:export\s+)?([A-Za-z_][A-Za-z0-9_]*)\s*=`。

**M2 — 行内 `#` 注释不剥离（作者已列）**
`KEY=val # comment` 的 value 会保留 `# comment`。当前 AK/SK 不含 `#`，无实际影响。

**M3 — `data/.env` 无法覆盖安装版配置（作者已列）**
`main.py:63-64` 先加载 `~/.fenshen/.env` 再 `data/.env`，且"补充不覆盖" → 源码开发者若想用 `data/.env` 覆盖安装版会失效。需注释明示。

**M4 — 事件循环阻塞（作者未标，比其 L2 更严重）** ⭐
`auth_send_code`（async，`main.py:517`）**同步调用** `send_sms_code`（`main.py:542`），内部 `requests.get(url, timeout=10)`（`main.py:506`）是**同步阻塞 IO**。最坏情况单次发码**阻塞整个事件循环 10 秒**，期间所有请求（含元神对话、看板）无法响应。作者只标 L2"高并发建议换 httpx"，但这是**当前就存在的同步阻塞**，不只是并发优化。
**建议**：`send_sms_code` 用 `await asyncio.to_thread(...)` 包裹，或改用 `httpx.AsyncClient`。

**M5 — 官网下载链接过期/不一致** ⭐（"下载文件"核心问题）
`site/index.html` 下载链接：
- **Windows** → `分身-v5.5-Windows-exe.zip`（Aug 14 构建，**落后当前 v6.4 至少 3 个版本**；site/ 内最新 Windows 包即 v5.5）
- **macOS** → `分身-v6.4-macOS.dmg`（Aug 23 11:59 构建，**不含 Aug 25 的短信修复**，因为修复是 v0.64.28→v0.64.29 的 WIP）

**后果**：用户从官网下载的包，要么版本严重过期（Windows），要么缺最新短信修复（macOS）。且 `dist/分身`（Aug 25 15:16，v0.64.29 onefile）尚未打包进 dmg。
**建议**：发版前重新构建 macOS dmg（含 v0.64.29）；Windows 若无新签名包，至少在下载页标注版本与"Windows 版暂缓更新"。

**M6 — 官网缺隐私政策/用户协议链接** ⭐（"跳转"核心问题）
v0.64.28 提交信息称"隐私政策/用户协议(官网+应用内)"，但实测：
- **应用内**（frontend/index.html:452/3129/3130）：有，跳 `http://39.105.6.135/privacy.html|terms.html` ✅（实测返回 200，内容为真实隐私政策）
- **官网**（site/index.html）：**无任何** privacy/terms 链接（grep 0 命中）❌

**后果**：官网访客无法查看隐私政策/用户协议，与"官网+应用内都已加"的表述不符。

### 🟢 Low（作者已列 + 新增）

- **L1**：`datetime.utcnow()`（`main.py:500`）Python 3.12+ 已弃用（DeprecationWarning）。
- **L3**：`_load_dotenv` 无日志，排障困难。
- **L4（新增）**：应用内隐私政策跳转用**裸 IP** `39.105.6.135`（记忆标注"S4 公网待修复外部阻塞"），且 `privacy.html`/`terms.html` 的**源文件不在本地仓库**（`find` 全项目 0 命中，仅存在于服务器）→ 版本不可控、裸 IP 脆弱、将来换域名/备案即失效。
- **L5（新增）**：官网资源冗余——`fenhen-teaser.mp4`（拼写错误）与 `fenshen-teaser.mp4` 重复（各 5.3MB）；`site/` 堆积 v5.4~v6.4 共 10+ 个旧安装包（dmg/zip），建议清理仅保留当前版本。
