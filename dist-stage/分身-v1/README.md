# 分身 v4.2（macOS 发行版）

本地优先的 AI 团队群聊助手，跑在你自己的电脑上。本包自带运行环境，无需 WorkBuddy。

## 一句话
分身是「你电脑上的数字分身」：能看所有项目、能派活、能质检，还能亲自上手执行命令、操作浏览器、读写文件。手机/其他设备只是远程看板。

## 安装与启动
1. 解压本包
2. 双击 **`安装.command`**（首次会联网装依赖，约几十秒）
3. 浏览器自动打开 `http://localhost:8002/`

之后每次使用，双击 **`启动.command`** 即可；停止双击 **`停止.command`**。

## 要求
- macOS 10.15+，已装 `python3`（Xcode 命令行工具或 Homebrew 均可）
- 首次安装需联网（拉取 FastAPI / uvicorn）；之后离线可用

## 安全模型（v4.x 重要变更）
分身拥有本机执行命令与读写文件的权限，因此安全是默认开启的：

- **默认只绑本机（127.0.0.1）**：外部设备无法直接打进来。这是 v4.x 相对旧版的关键修复——旧版默认绑 `0.0.0.0`，同一 WiFi 下等于开后门。
- **本地令牌鉴权**：首次启动自动生成令牌（`data/.auth_token`），所有 API 需携带令牌，无令牌返回 401。
- **危险命令需真人确认**（默认策略：仅危险命令弹窗，普通命令自动放行但全程审计）：AI 要执行危险命令时，会弹出系统对话框等你点头；客户端自带 `confirm` 无效，超时按拒绝处理。
- **清理有门禁**：破坏性清理（聊天/记忆/全部）强制真人确认，且操作前自动备份数据库。

### 局域网（手机/其他设备）访问
默认不开。如需让手机连同一 WiFi 看板，请在启动前设置环境变量：

```bash
FENSHEN_ALLOW_LAN=1
```

然后在「终端」中执行（或把变量加到 启动.command 前一行）：

```bash
FENSHEN_ALLOW_LAN=1 open 启动.command
```

开启后访问需携带令牌，令牌见 `data/.auth_token`。**仅在可信网络下开启。**

## macOS 打开 .command 提示「无法验证」怎么办？
这是苹果对网上下载文件的统一安全拦截（Gatekeeper），与本软件无关。二选一即可：

**方法 A（推荐，永久生效）**——打开「终端」粘贴运行（路径按你实际解压位置改）：
```
xattr -cr ~/Downloads/分身-v4.2
```
回车后再双击 `安装.command` 即可正常打开。

**方法 B（单次信任）**——右键 `安装.command` → 打开 → 弹窗中点「打开」。之后 `启动.command` / `停止.command` 也用同样方式首次打开一次即可。

## 说明
- 数据存于本包内 `data/fenshen.db`（本地 SQLite），不落云。
- 服务端口 **8002**（规避 8000 生产占用）。
- 元神 LLM 接 DeepSeek，密钥失效时自动降级（记录输入 + 提示），换有效 key 即恢复。
