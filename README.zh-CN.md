# 分身 · 本地优先的 AI 团队总管

> 你的数字分身 + 一支跑在**你自己电脑上**的 AI 团队。每个项目 = 一个群聊；元神（Meta-Agent）调度专才角色、跟踪进度、交付**可验证**的结果——文件、测试、覆盖率报告，全部落在本地 SQLite。

## 为什么是分身

大多数 AI 助手只回文本。分身**真的动手**：写文件、跑命令、开浏览器、测试自己的产出——只有存在可验证的交付物（pytest 日志、覆盖率报告、git 提交）才声称"完成"。

- 🗣️ **群聊即团队**：在项目群聊说"做个登录页"，元神拆卡、派前端/后端/测试角色，看板实时更新。
- 🧠 **你的数字分身（元神）**：从你的简历/对话/文档/反馈中蒸馏（带授权模型），被 5 条宪法约束，永远站在你这边。
- 🔄 **自进化**：每次任务沉淀 5 维权重的经验，晋升/淘汰/护栏让记忆 day-1 安全。
- 🎚️ **token 档位（0.64.14）**：即时问答元神单次直答（0.7s/~500 tokens）；小任务单角色速办；复杂工程才启动完整团队+质量门。同类任务实测 **198.9k→9.2k tokens（降 21.6 倍）、201s→4.6s（快 43 倍）**。
- 🔒 **本地优先且安全**：默认只绑 127.0.0.1、令牌鉴权、危险命令需真人系统级确认、宪法守卫不可被任何配置降级。

## 快速开始

**macOS**：下载 [分身-v6.4-macOS.dmg](site/分身-v6.4-macOS.dmg)，拖入 Applications 运行，浏览器自动打开 `http://localhost:8002/`。

**Windows**：下载 exe zip，解压双击 `Fenshen.exe`。

**源码运行**：
```bash
git clone https://github.com/fenshenplus/fenshen-os.git
cd fenshen-os
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
./启动分身.command   # 或 uvicorn backend.main:app --port 8002
```

## 安全模型

- 默认只绑 `127.0.0.1`；局域网需显式 `FENSHEN_ALLOW_LAN=1` + 令牌。
- 首次启动生成本地令牌（0600 权限），所有 API 必须携带。
- 危险命令（`rm -rf`、`git push --force`、格式化等）需**系统级真人确认**；客户端确认无效；超时按拒绝。
- **宪法守卫（v6.4）**：5 条不可覆盖——唯一委托人=本机用户；利益冲突护用户；钱/隐私/声誉/不可逆操作默认保守；用户有完全控制权；蒸馏他人须明示授权。
- 破坏性清理先自动备份数据库；全量审计日志。

## token 档位设计（0.64.14）

| 档位 | 触发 | 实测成本 |
|---|---|---|
| T0 即时直答 | 问答/闲聊 | 1 次调用 · ~500 tok · 0.7s |
| T1 单角色速办 | 明确小任务 | ~4 次调用 · ~9.2k tok · 4.6s |
| T2 团队协作 | 复杂/跨角色工程 | 质量门+验收（高成本换可验证交付物） |
| T3 长程自治 | 项目级无人值守 | 按任务摊薄、并发≤3、无人值守 |

支持项目级覆盖（`product_meta.tier`）+ 前端档位下拉；同模型团队复用共享上下文前缀（DeepSeek 前缀缓存）。
